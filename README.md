# 新竹市醫事人員年資證明排版工具

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

一份專為**新竹市衛生局**設計的**醫事人員年資證明**排版工具，旨在將醫事管理系統匯出的 Excel 或 CSV 檔案，快速轉換為專業、美觀且易於閱讀的證明文件。

本工具最大的特色是**完全在您的瀏覽器本機端運行**，無須安裝任何軟體。您上傳的檔案**不會經過任何網路伺服器**，確保所有敏感的個人資料（PII）都受到最嚴謹的保護。

## ✨ 功能特色

*   **🔒 絕對的資料安全**：檔案僅在瀏覽器內部處理，不依賴網路連線，確保個人資料零外洩風險。
*   **🚀 隨開即用**：無需安裝、無需設定，只要有瀏覽器就能立刻使用。
*   **📄 支援多種格式**：輕鬆讀取 `.xlsx`, `.xls`, `.csv`, `.txt` 等常見格式的醫事人員執業紀錄檔案。
*   **🎨 專業版面設計**：自動將原始資料排版成清晰、美觀的年資證明文件。
*   **💻 跨平台相容**：在 Windows, macOS, Linux 等任何可以執行現代瀏覽器的作業系統上都能順暢運作。
*   **🖨️ 友善列印與輸出**：提供一鍵列印功能，並可另存為 PDF 檔案，方便存檔或交付。
*   **🌐 完全離線運作**：所有核心程式庫 (Tailwind CSS, Lucide Icons, SheetJS) 皆已整合，即使在沒有網路的環境下也能正常使用。

## 🛠️ 技術棧

本專案採用簡潔且高效的前端技術打造：

*   **HTML5**: 負責結構與內容。
*   **Tailwind CSS**: 用於快速建構現代化的使用者介面。
*   **JavaScript (ES6)**: 核心的商業邏輯與互動功能。
*   **[Lucide Icons](https://lucide.dev/)**: 提供清晰、一致的圖示。
*   **[SheetJS (xlsx.js)](https://sheetjs.com/)**: 強大的 JavaScript 函式庫，用於解析與處理 Excel 檔案。

## 🚀 如何使用

操作流程非常簡單：

1.  **開啟工具**：直接在瀏覽器中開啟 `index.html` 檔案。
2.  **上傳檔案**：
    *   點擊「選擇檔案」按鈕，選取從醫事管理系統匯出的醫事人員執業紀錄檔案。
    *   或是，直接將檔案拖曳至上傳區域。
3.  **完成**：工具將自動解析資料並呈現在畫面上。
4.  **列印或儲存**：點擊右上角的「列印 / 存為 PDF」按鈕，即可將結果輸出。

您也可以點擊「使用範例資料試試看」，快速體驗本工具的排版效果。
